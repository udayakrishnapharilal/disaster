Java OOP Architecture
  • Inheritance: Base abstract User extended by Administrator, Victim, Volunteer.
  • Polymorphism: Overridden getRoleDescription(), polymorphic EmergencyDispatchable dispatching.
  • Encapsulation: Domain logic invariants in Shelter.allocate() and Resource.deductStock().
  • Abstraction: Decoupled interfaces Manageable<T, ID>, ReportGeneratorService.
  • Exception Handling: Custom checked/unchecked exceptions (ShelterFullException, InsufficientResourceException).
